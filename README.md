# Cat-Health-Tracker

A simple tracker for your cat health and various events. 
It works offline and can be installed to the Android home screen.

## Run it

It is a static site with no build step: host these files from the repository root (for example with GitHub Pages) and open `index.html`.

Your data is saved in the browser on the device you use.
If you and your partner use it, you can share an export and do a merge of the data to include both of your logs, the app detect similar ones (possible duplicates) to consolidate them in one single dataset.
