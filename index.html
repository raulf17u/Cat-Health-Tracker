Install MiauChart

Add MiauChart to your Home Screen for full-screen offline use:

iPhone / iPad (Safari): Tap the Share icon ⎋ at the bottom, then scroll down and tap Add to Home Screen.

Android (Chrome): Tap the ⋮ Menu in the top-right corner and select Install App or Add to Home Screen.

Desktop (Chrome / Edge): Click the install icon in the right side of the browser address bar.
